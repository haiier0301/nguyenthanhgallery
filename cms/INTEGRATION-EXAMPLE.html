CMS Integration Examples

This page demonstrates how to integrate CMS data into your pages.

Example 1: Load Artists List

<script src="cms/integration.js"></script>
<script>
  // Load all artists
  loadArtistsFromCMS();
</script>

Result:

Loading artists...

Example 2: Load Artworks for Nguyen Thanh (2002 Series)

<script>
  // Load artworks for specific artist and series
  loadArtworksByCMS('nguyen-thanh', '2002');
</script>

Result:

Loading artworks...

Example 3: Load Exhibition History

<script>
  // Load all exhibitions
  loadExhibitionsFromCMS().then(exhibitions => {
    exhibitions.forEach(ex => {
      console.log(ex.year, ex.title, ex.location);
    });
  });
  
  // Load only awards
  loadExhibitionsFromCMS('award').then(awards => {
    // Display awards
  });
</script>

Result:

Check console for exhibition data

Example 4: Auto-populate Artist Page

<!-- In artist page HTML -->
<div class="artist-intro-block">
  <h1 class="artist-name-large"></h1>
  <div class="artist-bio"></div>
</div>

<div class="artworks-grid"></div>

<script src="../cms/integration.js"></script>
<script>
  // Auto-load based on page URL
  initCMSIntegration();
  
  // Or manually specify
  loadArtistProfileFromCMS('nguyen-thanh');
  loadArtworksByCMS('nguyen-thanh');
</script>

Implementation Steps

  1. Add integration script to your HTML pages: 
    <script src="cms/integration.js"></script>
  2. Call load functions where needed: 
    loadArtistsFromCMS();      // For artists page
loadArtworksByCMS(artistId); // For artist detail page
loadExhibitionsFromCMS();    // For exhibitions page
  3. Ensure HTML structure matches expected selectors:
    • .artist-list-grid for artist names
    • .artist-thumbnails for artist thumbnails
    • .artworks-grid for artworks
    • .artist-name-large for artist name
    • .artist-bio for biography
  4. Test with CMS data:
    • Add/edit content in CMS
    • Refresh front-end page
    • Verify content updates
